# Hallmark in Caveman Locks

Hallmark (from `nutlope/hallmark`, MIT) is the anti-slop design skill for the
React/Vite frontend (`src/pages/*`, `src/components/*`). Use it when building or
redesigning UI so screens look *made*, not *generated*.

**Brand override — Hallmark bends to Caveman Locks, not the reverse.**
Ignore Hallmark's 20 catalog themes' palettes; the brand is fixed (CLAUDE.md):

- Palette: ochre `#C8860A`, charcoal `#2C2C2C`, off-white `#F5F0E8`, dark stone `#1A1A1A`.
- No blue buttons. Ochre is the only accent, used sparingly.
- No emoji in UI. Grainy/rough textures OK (cave-painting brand).
- Pick cards: bet info dominates, secondary info strongly recedes.

Use Hallmark for **structure, rhythm, typography, and the slop-test gates** —
apply the brand's colours and the `taste` skill on top. Treat Hallmark's
`references/color.md` themes as structural inspiration only.
